# Default wallpaper

`default.jpg` is the macOS Mojave "sand dunes (night)" wallpaper, downscaled from 5120×2880 to
3840×2160 and recompressed. Original: <https://4kwallpapers.com/images/wallpapers/macos-mojave-sand-dunes-mojave-desert-california-night-dark--4051.jpg>

The project owner supplied it as free to use. If you redistribute NodeDesk and are unsure about
the image's terms, replace this file with one you are sure about; the rest of the app does not
depend on it.
